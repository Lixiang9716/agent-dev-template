# 文档层级:一个事实一个家

[English](tiers.md) | 中文

每个事实只有唯一的家——负责它的层级。其他地方放链接。当两个地方需要同一事实时,漂移那天必有一处是错的。

| 事实 | 家 |
|---|---|
| agent 与人类的常设规则 | [AGENTS.md](../AGENTS.md) |
| 治理平面如何工作 | [architecture.md](architecture.zh.md) |
| 决策为什么做出、击败了什么 | `.agents/notes/`(Agent Notes) |
| 失败为什么发生、护栏为什么漏掉 | `docs/postmortem/` |
| 双语配对契约 | [i18n/README.md](i18n/README.zh.md) |
| 词数上限 | `scripts/doc-budgets.json` |
| 门禁定义与模式 | `gates.json` |
| 产品代码知识 | 产品平面自己的文档,由你拥有 |

一个新事实先选层级,然后只落一次。预算让每个家保持读者真正读得完的体量。
