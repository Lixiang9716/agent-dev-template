# 防御性模式

[English](defensive-patterns.md) | 中文

针对真实出过、且重新发现代价昂贵的缺陷类别的规则。每条陈述规则与它防的 bug 类别。只有带着 motivating 失败才允许新增模式——没有伤疤的模式是猜测。

## 独立报告正交结果

一个进程可能"超时了"且"退出码为 0",因为它捕获了信号。每个独立事实(`timedOut`、`signal`、`exitCode`)单独呈现;绝不把一个标志的报告嵌进另一个的分支,否则调用方会把被截断的运行读成干净的成功。

## 清理必须到达静止,而不是只发出请求

发出 kill 或 abort 就返回的清理会留下孤儿。发信号后要 await 子进程退出,并且先关监听器注册表再 kill,让迟到的完成保持静默。
