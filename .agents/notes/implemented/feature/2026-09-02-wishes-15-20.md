# Agent Note: wishes round III — adopt, doctor, note scaffolding, evidence prefetch, strict schema, default recording

Status: implemented

## Problem

Six gaps from the adopter's daily use. Template upgrades were all-manual
even for pure additions (hand-copying from site-packages). The
environment assumptions (gov on PATH, Python floor, executable hooks)
had no self-check — breakage surfaced as silence or a confusing crash.
Note checks arrived one audit too late (a typo'd note path lived until
commit). The review dossier assembled material but not evidence, so
grading still meant hand-searching. gates.json accepted unknown keys,
so "enable": false silently parked nothing — the quiet back door D24
had just closed. And trend history was opt-in and its absence
ambiguous.

## Decision

All six (D29). `gov init --adopt [file…|all]` lands only locally-missing
template files — never overwriting an existing one — records them in the
manifest, and the upgrade report's MISSING lines now carry a copy-paste
adopt command; modified-file adoption stays the D23 two-step.
`gov doctor` names environment problems rule-5 style (exit 1): gov
reachability, Python against the 3.9 floor, both pre-push copies'
executability, the strict gates schema, decisions-table parseability.
The hook template resolves gov robustly: GOV_BIN, then PATH (pipx-
compatible), then `python3 -m gov`. `gov note new` scaffolds at the
lawful path pre-validating the class against the closed set and the
D-reference against the decisions table; `gov note check` runs format,
placement, and dangling-D checks light enough for pre-commit. The review
dossier's rubric section attaches evidence candidates: backtick anchors
from each item's Checks field matched inline in the changed files
(±4 lines, at most two per item), labelled leads-to-verify, not
verdicts. load_config rejects unknown top-level and per-gate keys by
name. Run history records by default (local, gitignored, append-only —
reversing D28's opt-in sub-point), --no-record opts out, and trend
distinguishes never-recorded from not-enough-runs.

## Alternatives considered

- Adopting modified files too — rejected: that is the two-step
  philosophy's territory.
- Doctor auto-fixing — rejected: name, never repair; the fix must pass
  through a human.
- note new writing prose — rejected: skeleton plus pre-validation stops
  where ghost-writing decisions would begin.
- Warning on unknown keys — rejected: a gentle silent skip is still a
  silent skip.

## Consequences

A typo'd park key now aborts the run with the key named; a fresh
template file lands with one copy-paste; the environment reports its
own health; notes are validated before prose is invested; reviewers
verify evidence instead of hunting it; and gate-duration trends exist
unless asked not to. The flag registry in audit_notes and the strict
schema together pin the CLI surface from both sides.
